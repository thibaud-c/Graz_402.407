# HTML structure with flex and grid

[CSS tutorial](../../tutorials/css.md) · [Snippet index](../README.md)

Lab 05's layout is useful before adding a map. This version has one stylesheet, meaningful text, working navigation links, and no JavaScript. It removes the expired remote-image URL, empty link targets, broken CSS values, and a button whose function was missing.

Open `index.html` with Live Server. Click each navigation link. Resize to a phone width: the text and aside should stack without horizontal scrolling. Use Inspector to identify the flex container, grid container, and box-model properties. Change the columns from `2fr 1fr` to `1fr 1fr` and explain the effect.
