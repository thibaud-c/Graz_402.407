    How might a default filter, label or map view influence attention or action? Separate an observed change from a possible effect.

    Try changing the code
    1. In index.html, change the heading and explain your new question.
    2. In style.css, change the emphasis of the observation cards. Compare on a phone-sized window.
    3. In app.js, change one record's category. Predict the result of filtering before reloading.
