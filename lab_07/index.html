The zoning effect

A web map groups observations according to a rule written by its author. Here, both views use the same study area, the same requests and exactly two zones. Turning the boundary gives each zone a different set of points. Geographers call this the zoning effect. It is one part of the modifiable areal unit problem (MAUP).

Write a two-sentence caption. Compare the two splits using the counts you observed. Then name one thing you would need to know before recommending where Graz should install a bench. Think about who was asked, or where benches already exist.
